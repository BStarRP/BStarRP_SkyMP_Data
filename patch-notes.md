# Patch notes

## Changes
- Improved client performance when hosting movement for several actors.
- Updated silver weapons so they cut deeper into the undead, vampires, ghosts, and werewolves. A normal blade hits a werewolf in full.
- Fixed a swing so it still lands while you are moving, and a power attack carries farther into the fight.
- Fixed a killing blow so the body falls.
- Fixed setting a corpse down so it stays where you leave it.
- Fixed flesh spells so a heal, a light, or a shell leaves the cloak on you. A stronger flesh spell still takes its place.
