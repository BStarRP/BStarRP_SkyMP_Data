# Patch notes

## Changes
- Fixed the notice board so leaving it clears the page.
- Fixed the Skyforge so its leather rack is a leatherworking bench.
- Updated Dawnstar so a death brings you back to the Temple of Zenithar.
- Updated cutting a shank takes the same smelting skill as that metal.
- Improved the Witchhunter so a silvered shot bites harder into the dead, the daedra, and the summoned, and those prey show on the compass while the calling is worn.
- Improved the wilds so skeletons and the other creatures match the land they stand on. The high snow is a harder fight, and the roads and towns stay as they were.
- Fixed the MIDI lute so a string goes quiet when you let it go.
- Added a search on the notice board, so a goods job can name any item in the world.
- Improved the notice board so a choice hangs over the page and the notices stay where they are.
