# Patch notes

## Changes
- Fixed the stance key so the first press shows Low, Mid, or High.
- Fixed enchanted weapons and armor so their effects apply when you also carry a plain copy of the same item.
- Fixed an honorable death in Sovngarde so you appear on the bridge as a ghost and can walk.
- Added temples in the smaller towns. Dying nearby sends you there, and you can change your skill plan inside.
- Fixed resisted magic so Calm, Paralyze, Mesmerize, and other spells flash and play a sound when they fail to land.
- Improved character select so the character list and the buttons under it have space between them.
- Reworked petting so feeding is what tames an animal, and a pat only helps after a meal.
